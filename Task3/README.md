# Задание 3. Архитектура ИИ-сервисов

[Основной документ](architecture.md) содержит четыре C4-диаграммы: Container и Component флагмана №1, Container №2 и №18. Дополнительный DFD раскрывает путь данных. Там же находятся ответственность компонентов, F1–F8/D1–D5, fallback, мониторинг и таблица угроз TB1–TB5.

Выходные контракты: [ranking](contracts/rank.schema.json), [документы](contracts/document.schema.json), [синтетические примеры](contracts/examples.json). Структура проверяется JSON Schema; источник, свежесть, права и human approval требуют дополнительных проверок. Команд провести/заблокировать платёж в контрактах нет.

Схемы доступны как встроенные PNG и масштабируемые SVG; [редактируемый генератор](../tools/build_diagrams.py) хранит явные узлы и связи.
