# Task2. Данные, размещение и кандидаты

## Четыре пути получения сигнала для флагмана

| Путь | Что получаем | Ограничение и цена | Решение |
|---|---|---|---|
| Экспертная контрольная выборка | Независимое от модели суждение о необходимости расследования, оценка пропущенных правилами случаев | 1 000/месяц ×12 мин=200 ч, требуется инструкция и вероятность включения. Редкие схемы могут не встретиться | Постоянная случайная/стратифицированная ветвь, бюджет из общей ёмкости, не только модельная очередь |
| Разметка финмонитором | Более близкий процессу эталон и калибровка критериев | Двойная разметка/арбитраж; согласие экспертов не доказывает юридическую квалификацию | Включить контроль согласованности и класс «недостаточно данных» |
| Слабые метки | Правила, внешние флаги, эскалации и outcomes для baseline/исследования | Дёшево извлечь, дорого ошибиться: selection bias, задержка, circular learning | Не называть схемами; отдельные таблицы событий и delayed joins; supervised challenger только с целевой меткой «эскалация» |
| Без учителя | Аномальность/приоритет без готовых positive/negative | Новые нормальные клиенты тоже аномальны; score не вероятность. Нужен ручной независимый замер | IsolationForest — основной кандидат для shadow, правила остаются baseline |

Рекомендуется сочетание контроля + экспертной инструкции + unsupervised ranking. Слабые метки полезны для диагностики. Создание «чистых» отрицательных меток из непроверенного потока запрещено. Сохранить outcome_time, observation_cutoff, adjudication_version, inclusion_probability; созревшие исходы переоценивать отдельно, без переписывания первоначального суждения.

## Карта размещения — hard constraints прежде сравнения

| Вариант | №1 | №2/18 | Условие допуска |
|---|---|---|---|
| Общедоступный API | Исключён для реальных операций | Исключён для реальных документов | Нет подтверждения права передачи, хранения, использования для обучения и состава субобработчиков. Цена/удобство не компенсируют отсутствие допуска |
| Выделенный endpoint провайдера | Резерв, сейчас не допущен | Резерв, сейчас не допущен | Договор, регион, журнал доступа, изоляция, запрет обучения, удаление копий, SLA и выход должны быть подтверждены |
| Self-hosted в облаке | Условная альтернатива | Условная альтернатива | Приватная сеть не заменяет правовой допуск обработчика; согласовать ключи, копии, сетевой выход и место хранения |
| On-prem | Выбран для пилота при A1/A2 | Выбран при A1/A2 | Изоляция данных и управления, роли, capacity, разрешённые модели; до подтверждения предпосылок обработка реальных данных не начинается |
| Гибрид | Не выбран | Не выбран | Локальная идентификация не делает финансовые тексты обезличенными; дополнительная граница передачи без доказанной выгоды |

Пилот: изолированный batch, синтетика для интеграции, затем разрешённый shadow. Целевой прод: две зоны отказа on-prem для очереди/API/хранилища, независимый baseline, восстановление и capacity только после gates. Облако используется как рыночный ценовой ориентир в Task4, не как объявленный факт закупки.

Сравнение допущенных вариантов: качество на acceptance set 40%, эксплуатация/восстановление 25%, TCO 20%, переносимость 15%. До замеров баллы качества не выдумываем. Среди on-prem/условного облака временно выбираем on-prem по уменьшению числа внешних потоков; окончательное ранжирование после допуска и бенчмарка. Hard constraints не входят в средневзвешенный балл.

## Shortlist и проверка

| Инициатива | Кандидаты и почему | Проверка / условие смены |
|---|---|---|
| №1 | Действующие правила; IsolationForest; supervised tree challenger на экспертной метке только после накопления gold | Фиксированное residual K, будущие клиенты/время, 3 000 экспертных проверок начального бюджета; CI и stop из P1. Выбрать rules, если прирост не доказан. Обучение на всех 25 млн строк не обязательно: репрезентативный sample fit и batch score полного допущенного потока; размер/память определит нагрузочный тест |
| №2 | Tesseract5 rus+eng baseline; PaddleOCR с совместимым Cyrillic recognition checkpoint и detector | 600 страниц/закрытые 300, фото/поворот/таблицы/слабый контраст. Проверить состав языков конкретных весов, hash, лицензию и supply chain; PP-OCRv5 по умолчанию не объявляем подходящим для кириллицы. Если не проходит кириллицу — исключить до качества/стоимости |
| №18 | Правила + словарь; XLM-R base с дообученным token classification и детерминированной связью периодов/единиц | 400 пакетов с holdout по клиентам/формам, 50-пакетный факторный эксперимент. Base checkpoint сам не извлекает показатели; нужен gold, обучение, контроль лицензии и замер CPU/GPU |
| №18, исключённый | LayoutLMv3-base | Лицензия весов non-commercial: коммерческий пилот исключён без отдельного разрешения. Преимущество layout не снимает запрет |

Веса моделей, контейнеры, preprocessing, словарь, schema и test-set manifest фиксируются digest до пилота. Автоматическая загрузка «latest» и доступ workers в интернет отключены. Упоминание кандидата не означает его установку/запуск в рамках этой архитектурной работы. Версии и зависимости закрепляются инженерами при реализации, после security review.

Все acceptance-пороги — [паспорта](passports.md); фактическое качество/latency пока неизвестно. Общая ошибка допуска: 0 событий незаконной передачи/автоматического бизнес-действия. Отрицательный тест считается пройденным, только если сервис воздержался/отдал человеку и сохранил причину.
