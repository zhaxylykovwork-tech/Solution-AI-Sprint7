# ADR-003. Извлечение с источником, единицей и периодом

Статус: предварительное. Дата: 08.11.2026. Инициатива №18, [паспорт P3](passports.md).

Контекст: нужен проверяемый перенос показателей из разных форм, а не генерация отчёта. Ограничения: каждое значение имеет исходный span; отсутствующее значение null, конфликт REVIEW; критичные поля подтверждает андеррайтер, кредитного действия модель не выполняет. Коммерчески несовместимые веса исключаются до качества.

Критерии: exact match кортежа 45%, abstention/источник 25%, TCO 15%, переносимость/эксплуатация 15%; баллы до эксперимента неизвестны.

| Вариант | За | Против | Решение |
|---|---|---|---|
| Правила по формам и словарь | Точность на известных формах, прозрачность | Не покрывает свободные/новые формы | Baseline и часть гибрида |
| XLM-R base + token head + resolver | Многоязычная база, локальный deployment | Нужна разметка/дообучение, layout теряется, ресурсы не измерены | Challenger, не готовый extractor |
| LayoutLMv3-base | Учитывает изображение/layout | Опубликованная лицензия весов non-commercial | Исключён для коммерческого пилота без отдельного разрешения |
| LLM API | Быстрая демонстрация формата | Нет допуска передачи, риск правдоподобного отсутствующего поля | Исключён; локальная LLM возможна в будущем только отдельным ADR и тестом |

Пилот on-prem: 400 пакетов и факторный E3; решение «правила либо обучаемый extractor» принимается по закрытому тесту. Прод сохраняет post-validation и human approval. Допущения A1/A2/A7 о правах, корпусе и объёме критичны. Риски: неверный период/множитель → typed decimal+проверки заголовков, OCR provenance и source verification; конфликты источников не разрешаются средним значением.

Выход: собственный JSON Schema и независимый validator, экспорт gold и manifests внутри разрешённого контура, смена модели с полной регрессией и возвратом к ручному вводу. Триггеры: провал exact match/abstention, новая форма/язык, любой принятый unsupported value, рост стоимости/latency >30%, изменение лицензии. История v0.1 08.11.2026: локальный гибрид с первичным правиловым baseline; качество не измерено.
