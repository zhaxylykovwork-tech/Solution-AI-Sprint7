# ADR-002. Локальный OCR с подтверждением критичных полей

Статус: предварительное. Дата: 08.11.2026. Инициатива №2, [паспорт P2](passports.md).

Контекст: сканы/фото требуют перепечатки, но доля OCR в 1,5 часах пакета неизвестна. Жёсткие ограничения: без допуска реальных документов не обрабатываем, наружу не передаём; OCR не меняет реквизиты в кредитной системе без подтверждения.

Критерии после допуска: critical exact match 45%, время оператора 25%, TCO 15%, переносимость/эксплуатация 15%. Измеренных баллов нет.

| Вариант | За | Против | Решение |
|---|---|---|---|
| Ручной ввод | Проверенный fallback | Время и опечатки | Baseline |
| Tesseract5 rus+eng | Локально, открытая лицензия, простой CPU baseline | Фото и таблицы могут требовать preprocessing | Первый кандидат |
| PaddleOCR с кириллическими весами | Альтернативный pipeline | Проверить язык и лицензию checkpoint, ресурсы/качество неизвестны | Challenger после входной проверки |
| Public/выделенный OCR API | Меньше эксплуатации | Передача/договор/копии не согласованы | Public исключён; выделенный — условный резерв |

Пилот: offline 600 страниц, shadow и UI исправлений; прод только после теста и оценки реальной нагрузки. Предположения: разрешённый корпус, реальные фото, возможность ручного подтверждения; источник — A1/A2/A7, все критичны. Риски: ошибка суммы/разряда → проверка критичных полей; malformed PDF → sandbox/лимиты; утечка → rbac/encryption/egress deny. Нет обещания распознавания рукописей.

Выход: единый span/bbox контракт, сохраняются исходный hash и OCR version; смена движка через адаптер, регрессия на том же закрытом наборе, ручной ввод при отказе. Триггеры: новые язык/форма, CER/critical match ниже P2, очередь не укладывается в 2 мин, смена лицензии/цены или неподтверждённые права. История v0.1 08.11.2026 — локальный OCR + human confirmation; измерения не проводились.
