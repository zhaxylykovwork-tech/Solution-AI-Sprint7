# Проверка материалов

08.11.2026. Проверены архитектурные материалы; данных RetailBank и работающего сервиса в репозитории нет.

- `python tools/validate.py`: локальные ссылки,18 строк триажа, JSON/SVG,5 пар диаграмм, воспроизводимость TCO, положительные/отрицательные контрактные примеры. Для schema нужен `jsonschema`.
- `python Task4/calculate.py`: значения сверены с таблицами12/24 месяца. Для малых unit costs сохранено6 знаков; деньги округляются до копеек только при выводе.
- Все5 PNG просмотрены: уровни C4, типы, направления, легенда, подписи, пунктирные границы и внешний downstream. SVG позволяет масштабировать без потери текста; source Python редактируем.
- Проверены различия score/решение/approval, escalation/outcome/formal confirmation, baseline/целевые пороги/фактические результаты, денежные расходы/стоимость ёмкости.
- Подтверждена доступность первичных внешних источников на дату сверки; качество кандидатов на банковском наборе неизвестно.

Не подтверждены этим документом: правовой допуск, доступность реальных данных/мощностей, качество/latency моделей, фактический банковский эффект и отправка проекта учебной платформе. Это условия будущего пилота и отдельный шаг сдачи.
