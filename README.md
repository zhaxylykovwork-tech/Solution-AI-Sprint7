# RetailBank: приоритизация проверок и обработка документов

Архитектурное решение для учебного кейса. Флагман №1 ранжирует операции для финансового мониторинга. Дополнительные инициативы №2 и №18 распознают документы и извлекают показатели для проверки андеррайтером.

Решение: ограниченный пилот в банковском контуре; промышленный запуск зависит от данных, правового допуска и измеренного эффекта. Модели не обучались на данных банка, метрики качества не измерялись. Все целевые числа ниже — проектные критерии, а не результаты эксперимента.

Диаграммы доступны как SVG и PNG; редактируемый источник — `tools/build_diagrams.py`. PNG встроены в Task3. Контракты — JSON Schema, примеры полностью синтетические.

Проверка из корня: установить `jsonschema`, затем `python tools/validate.py`; пересчёт: `python Task4/calculate.py`. Для перегенерации изображений: Python + Pillow, `python tools/build_diagrams.py`. Код расчёта использует только стандартную библиотеку. Публикуются только материалы решения; данных клиентов, моделей с обучением на банковских данных и учебных конспектов здесь нет.
