# Матрица требований и проверка решения

Составлен по доступному описанию проекта и шаблону. Фактическая страница сдачи на момент подготовки закрыта; перед отправкой требуется сверить её дополнительные условия. Эта матрица подтверждает подготовку материалов, не отправку проекта платформе.

| Требование | Артефакт | Проверка |
|---|---|---|
| Все18 вердиктов и вопросы неоднозначным | [Task1](Task1/triage.md) | Ровно18 пронумерованных строк, категории и обоснования |
| №1 + две ML/гибрид инициативы | [Канвас](Task1/triage.md), [паспорта](Task2/passports.md) | №1,2,18; ценность/выполнимость/данные/риск; разделы1–5 для каждой |
| Операция×модальность, модельный/бизнес-выход, gold | [P1–P3](Task2/passports.md) | Ранжирование не квалификация схемы; OCR не финансовое значение; extraction не кредитное решение |
| Четыре пути сигнала при отсутствии меток | [Selection](Task2/selection.md) | Контроль/финмонитор/weak labels/unsupervised, стоимость и bias; случайный контроль сохраняется |
| Data readiness для трёх | [Разделы4](Task2/passports.md) | Источники, права, владельцы, объём/важные классы, качество, labels, prod availability, bias, статус+план |
| Качество и эксперименты | [Разделы3/5](Task2/passports.md) | Baseline, size/slices, рабочая точка, неизвестные actual metrics, thresholds/основание, stop/guardrails |
| Карта5 вариантов размещения | [Selection](Task2/selection.md) | Hard constraints раньше весов, пилот/прод отдельно |
| Shortlist, приёмочные данные, смена решения | [Selection](Task2/selection.md) | Реальные кандидаты с первичными источниками; язык/лицензия до качества, нет выдуманного benchmark |
| ADR флагмана и две коротких ADR | [ADR-001](Task2/ADR-001.md), [002](Task2/ADR-002.md), [003](Task2/ADR-003.md) | Ограничения, веса, варианты, решение, допущения, риски, выход, триггеры; история001 v0.1–v0.4 сохранена |
| C4 Container+Component №1, Container №2/18 | [Архитектура](Task3/architecture.md) | Четыре C4 PNG/SVG визуально проверены, уровни/типы/потоки подписаны. DFD отдельно |
| ML/code/human, sync/async/batch и fallback | [Архитектура](Task3/architecture.md) | F1–F8/D1–D5, SLA/retry/idempotency, обязательные проверки независимо от ML |
| Контракт/валидация до действия | [Schema](Task3/contracts/rank.schema.json), [document](Task3/contracts/document.schema.json) | JSON Schema positive/negative examples; семантические проверки источника/свежести явно отделены от schema |
| Мониторинг: вход, модель, человек, бизнес | [Таблица](Task3/architecture.md) | Порог, действие и владелец; заданные цели не объявлены измерениями |
| Пунктирные TB и отдельная таблица угроз | [Диаграммы и STRIDE](Task3/architecture.md) | TB1–TB5, threat→control→negative check, нет угроз мелким текстом на диаграмме |
| TCO1–2 года, рыночные цены, допущения | [Task4](Task4/tco-and-pilot.md), [расчёт](Task4/calculation.json), [источники](sources.md) | Пересчёт python, ставки/объём/стоимость ошибки не названы фактами; расходы на данные/UI/безопасность/обновления/выход |

| Пилот/успех/stop/итоговый ADR | [План](Task4/tco-and-pilot.md), [ADR001](Task2/ADR-001.md) | Ограниченный пилот; no-go прод без эффекта/допуска; клиентские guardrails |
